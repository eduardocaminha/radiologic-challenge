# Radiologic Workstation

[English below](#radiologic-workstation-1)

Showcase público e permanente de workstations de radiologia criadas por qualquer pessoa: viewer, pilha de exames, IA, agente para conversar com a pilha e laudo. Pode ser construído com IA: o que importa é a experiência. Não há prazo nem prêmio. O ranking vem do voto de quem entra com Google ou GitHub em [challenge.radiologic.io](https://challenge.radiologic.io).

## Como participar

1. Leia o [regulamento](https://challenge.radiologic.io/pt/rules). O código precisa ser aberto, a demo precisa ser navegável e os dados precisam vir de base pública com licença declarada.
2. Use o [kit de dados](https://challenge.radiologic.io/pt/kit) ou outra base pública. Exame de paciente real fora de base pública não é aceito.
3. Envie de um destes jeitos:
   - **Pelo site:** [challenge.radiologic.io/pt/submit](https://challenge.radiologic.io/pt/submit).
   - **Por aqui:** abra uma issue com o formulário "Enviar uma workstation". Um robô responde na issue com os campos que faltam ou com a confirmação. Depois, entre no site com a mesma conta do GitHub para adicionar as imagens, aceitar o regulamento e mandar para moderação.
   - **Com um agente:** peça ao seu agente de código para seguir o [`AGENTS.md`](AGENTS.md). Ele prepara o rascunho pela issue, e você revisa e envia no site.

Toda submissão passa por moderação antes de aparecer na galeria.

## O que tem neste repositório

- `.github/ISSUE_TEMPLATE/viewer.yml`: o formulário de submissão.
- `AGENTS.md`: como um agente de código prepara uma submissão.
- `.github/workflows/intake.yml`: o workflow que envia cada issue ao site, com assinatura HMAC, e comenta o resultado.

Os projetos não ficam aqui. Cada autor mantém o próprio repositório.

## Uso não clínico

Os projetos do desafio são experimentais, de finalidade educacional e de pesquisa. Não são dispositivos médicos e não devem ser usados para diagnóstico ou conduta.

# Radiologic Workstation

A public, permanent showcase of radiology workstations built by anyone: viewer, exam worklist, AI, an agent to talk to the worklist, reporting. It can be built with AI: the experience is what counts. There is no deadline and no prize. The ranking comes from the votes of people who sign in with Google or GitHub at [challenge.radiologic.io](https://challenge.radiologic.io/en).

## How to take part

1. Read the [rules](https://challenge.radiologic.io/en/rules). The code must be open source, the demo must be usable, and the data must come from a public dataset with a stated license.
2. Use the [data kit](https://challenge.radiologic.io/en/kit) or another public dataset. Real patient studies outside public datasets are not accepted.
3. Submit in one of these ways:
   - **On the site:** [challenge.radiologic.io/en/submit](https://challenge.radiologic.io/en/submit).
   - **Here:** open an issue with the "Enviar uma workstation" form. A bot replies on the issue with the missing fields or a confirmation. Then sign in on the site with the same GitHub account to add the images, accept the rules and send it for moderation.
   - **With an agent:** ask your coding agent to follow [`AGENTS.md`](AGENTS.md). It prepares the draft through the issue, and you review and send it on the site.

Every entry is moderated before it shows up in the gallery.

## Non-clinical use

The projects in this challenge are experimental for education and research. They are not medical devices and must not be used for diagnosis or clinical decisions.
