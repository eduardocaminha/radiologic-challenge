# Segurança

Relate vulnerabilidades por e-mail para caminha@radiologic.io, sem abrir issue pública. Inclua os passos para reproduzir e o impacto. A resposta inicial sai em até 5 dias úteis.

Vale para o código deste repositório, para challenge.radiologic.io e para o repositório de submissões. Projetos enviados por terceiros ficam fora do escopo: relate ao autor de cada um.

Nunca envie dado de paciente real, nem como prova de conceito.
